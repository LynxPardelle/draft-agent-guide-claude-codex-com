# Agent Guide Claude/Codex

Public draft source for the Claude/Codex agent-learning guide.

## Release Flow

- Work lands on `dev`.
- Testing deploys after a pull request from `dev` to `test` is merged.
- Production deploys after a pull request from `test` to `main` is merged.

Before publishing or merging public draft changes, run the public-safety audit from the Zoolandingpage hub.
